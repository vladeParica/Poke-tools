# Credits and sources

## Devon Studios — LuaScripts

These bots are built on [**DevonStudios/LuaScripts**](https://github.com/DevonStudios/LuaScripts)
(Devon Studios x Real.96, GPL-3.0 license), a collection of Lua scripts for RNG
manipulation in the Pokémon games.

From [`Gen 3/VBA/FRLG_RNG_2.0.lua`](https://github.com/DevonStudios/LuaScripts/blob/main/Gen%203/VBA/FRLG_RNG_2.0.lua)
and [`Gen 3/VBA/E_RNG_2.0.lua`](https://github.com/DevonStudios/LuaScripts/blob/main/Gen%203/VBA/E_RNG_2.0.lua)
we took the base memory addresses, the frame and initial seed reading, and the name
tables (species, natures, moves).

That repository has more scripts that could be useful for future features:

| Script | What for |
|---|---|
| `Side Beta/Gen3/FRLG_Pickup_RNG.lua` | Pickup (items) RNG in FRLG |
| `Side Beta/Gen3/FRLG_Critical_Hit_RNG.lua` | Critical hit RNG in FRLG |
| `Gen 3/BizHawk/FRLG_RNG_2.0_BizHawk.lua` | BizHawk version |
| `Gen 3/VBA/RS_RNG_2.0.lua`, `E_RNG_2.0.lua` | Ruby/Sapphire and Emerald |
| `Gen 3/VBA/Side/` | Pokérus, Feebas, lottery, Mirage Island (RSE) |

## pret/pokefirered

[pret/pokefirered](https://github.com/pret/pokefirered) is the FireRed decompilation. It is
the source of the memory symbols (`gBattleMons`, `gMain`…), the battle script opcodes and
the tables generated by `trainbot/tools/gen_tables.py` (base stats, EV yields per species,
level-up moves, encounters per area).
